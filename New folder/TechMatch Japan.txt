# TechMatch Japan — Full Build Prompt

## Project Overview

Build a bilingual (Japanese/English) IT career intelligence web application called "TechMatch Japan." 
This is a full-stack web app for IT engineers in Japan to analyze job markets, compare salaries by 
technology, identify skill gaps, and track career development.

**Purpose:** Portfolio project to demonstrate full-stack engineering skills to Japanese employers.

**Live demo URL:** https://techmatch-japan.s3.amazonaws.com (deploy at end)

---

## Tech Stack (DO NOT DEVIATE)

- Frontend: React 18 (Vite), Chart.js (react-chartjs-2), i18next (react-i18next), React Router v6
- Backend: Node.js 20, Express.js
- Database: PostgreSQL 15
- Auth: JWT (jsonwebtoken) + bcryptjs
- Styling: CSS Modules or Tailwind CSS (pick one, stay consistent)
- Deployment: AWS S3 (frontend), AWS EC2 or Elastic Beanstalk (backend), AWS RDS (database)
- Version Control: Git + GitHub

## Database Schema

### Table: users
| Column | Type | Notes |
|---|---|---|
| id | SERIAL PRIMARY KEY | Auto-increment |
| email | VARCHAR(255) UNIQUE NOT NULL | Login email |
| password_hash | VARCHAR(255) NOT NULL | bcrypt hashed |
| display_name | VARCHAR(100) | Display name |
| preferred_language | VARCHAR(5) DEFAULT 'ja' | 'ja' or 'en' |
| skills | TEXT[] | Array of skill names |
| created_at | TIMESTAMP DEFAULT NOW() | |
| updated_at | TIMESTAMP DEFAULT NOW() | |

### Table: job_listings
| Column | Type | Notes |
|---|---|---|
| id | SERIAL PRIMARY KEY | |
| title_ja | VARCHAR(255) | Japanese title |
| title_en | VARCHAR(255) | English title |
| company | VARCHAR(255) | Company name |
| location | VARCHAR(100) | City |
| is_remote | BOOLEAN DEFAULT FALSE | Remote OK flag |
| salary_min | INTEGER | Annual min (JPY) |
| salary_max | INTEGER | Annual max (JPY) |
| experience_years | INTEGER | Required years |
| career_changer_friendly | BOOLEAN DEFAULT FALSE | Accepts career changers |
| employment_type | VARCHAR(50) | 'full_time', 'contract', etc |
| description_ja | TEXT | Japanese description |
| description_en | TEXT | English description |
| created_at | TIMESTAMP DEFAULT NOW() | |

### Table: job_skills (junction table)
| Column | Type | Notes |
|---|---|---|
| id | SERIAL PRIMARY KEY | |
| job_id | INTEGER REFERENCES job_listings(id) | |
| skill_name | VARCHAR(100) | e.g. 'AWS', 'React' |

### Table: saved_searches
| Column | Type | Notes |
|---|---|---|
| id | SERIAL PRIMARY KEY | |
| user_id | INTEGER REFERENCES users(id) | |
| search_name | VARCHAR(100) | |
| filters | JSONB | Stored filter parameters |
| created_at | TIMESTAMP DEFAULT NOW() | |

## API Endpoints

### Auth
```
POST   /api/auth/register     { email, password, displayName, preferredLanguage }
POST   /api/auth/login        { email, password }
GET    /api/auth/me           (requires JWT token in Authorization header)
```

### Jobs
```
GET    /api/jobs
  Query params:
    ?location=Tokyo
    &salary_min=3000000
    &salary_max=6000000
    &experience_max=1
    &remote=true
    &career_changer=true
    &skills=AWS,React,Python
    &language=ja
    &page=1
    &limit=20
    &sort=salary_desc

GET    /api/jobs/:id          Single job detail

GET    /api/jobs/skills       Returns all unique skills in the database
```

### Analytics
```
GET    /api/analytics/salary-by-tech
  Returns: [{ tech: "AWS", avg_salary: 5200000, count: 45 }, ...]

GET    /api/analytics/jobs-by-location
  Returns: [{ location: "Tokyo", count: 120 }, ...]

GET    /api/analytics/skills-demand
  Returns: [{ skill: "JavaScript", count: 180 }, ...]

GET    /api/analytics/salary-vs-experience
  Returns: [{ experience: 0, avg_salary: 3500000 }, { experience: 1, avg_salary: 4200000 }, ...]

GET    /api/analytics/career-changer-stats
  Returns: { total_jobs: 200, career_changer_friendly: 156, percentage: 78 }

GET    /api/analytics/overview
  Returns: { total_jobs, avg_salary, remote_count, career_changer_count }
```

### Skill Analyzer
```
POST   /api/analyzer
  Body: { skills: ["C#", "JavaScript", "AWS"] }
  Returns: {
    match_rate_by_job: [
      { job_id: 1, title: "Cloud Engineer", match_rate: 68, missing: ["Python", "Docker"] },
      ...
    ],
    overall_stats: {
      total_matching_jobs: 45,
      avg_match_rate: 62,
      most_demanded_missing: ["React", "Python", "Docker"],
      recommended_next: ["React", "TypeScript"]
    }
  }
```

### User (requires auth)
```
GET    /api/user/saved-searches
POST   /api/user/saved-searches   { searchName, filters }
DELETE /api/user/saved-searches/:id
PUT    /api/user/profile          { displayName, preferredLanguage, skills }
```

## Features
- **Salary Analytics** — Visualize salary data by technology, city, and experience level
- **Job Listings** — Browse and filter 50+ IT positions with advanced filtering
- **Skill Gap Analyzer** — Input your skills, see matching jobs and recommended skills
- **Bilingual UI** — Full Japanese and English support with language switcher
- **User Authentication** — Register, login, save searches and skill profiles
- **Responsive Design** — Works on desktop, tablet, and mobile

## Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React 18, Vite, Chart.js, i18next |
| Backend | Node.js, Express.js |
| Database | PostgreSQL 15 |
| Auth | JWT + bcryptjs |
| Cloud | AWS S3, CloudFront, EC2, RDS |
| Version Control | Git + GitHub |

## Architecture
```
[S3 + CloudFront] → [EC2 + Express API] → [RDS PostgreSQL]
```

## API Endpoints
| Method | Endpoint | Description |
|---|---|---|
| POST | /api/auth/register | Register new user |
| POST | /api/auth/login | Login |
| GET | /api/auth/me | Get current user |
| GET | /api/jobs | List jobs with filters |
| GET | /api/jobs/:id | Get single job |
| GET | /api/jobs/skills | Get all skills |
| GET | /api/analytics/salary-by-tech | Salary data by tech |
| GET | /api/analytics/jobs-by-location | Jobs by city |
| GET | /api/analytics/skills-demand | Skills demand ranking |
| GET | /api/analytics/salary-vs-experience | Salary vs experience |
| GET | /api/analytics/career-changer-stats | Career changer stats |
| GET | /api/analytics/overview | Dashboard overview |
| POST | /api/analyzer | Analyze skills vs jobs |

## Local Setup
```bash
# Clone
git clone https://github.com/tejas-5/techmatch-japan.git
cd techmatch-japan

# Backend
cd server
npm install
cp .env.example .env  # Edit with your database credentials
psql -f schema.sql
node data/seed.js
npm run dev

# Frontend
cd ../client
npm install
npm run dev
```

## Environment Variables
```
DATABASE_URL=postgresql://user:pass@localhost:5432/techmatch
JWT_SECRET=your-secret-key
PORT=5000
```

## Critical Rules

1. Every component must support bilingual rendering using react-i18next
2. All API responses return JSON with consistent format: { success: boolean, data: any, error?: string }
3. All database queries use parameterized queries (no string interpolation)
4. JWT tokens expire in 7 days
5. Passwords must be hashed with bcryptjs (10 rounds)
6. All pages must be responsive (mobile-first, minimum 375px)
7. Loading states on every API call
8. Error handling on every API call — display user-friendly messages
9. No placeholder data in production — all data comes from the database
10. README must include screenshots, setup instructions, and API documentation
